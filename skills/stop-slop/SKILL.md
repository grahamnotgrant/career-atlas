# Writing rules

These are original Career Atlas instructions. They require no external skill installation.

1. State the fact or action in the first sentence. Remove introductions that announce what the text will do.
2. Replace vague praise with evidence: the person's action, the work produced, and an outcome the source supports.
3. Preserve the user's meaning and voice. Do not add a metric, responsibility, credential or degree to improve the sentence.
4. Use familiar words. Remove jargon unless the employer uses it for a real requirement the candidate meets.
5. Delete repeated claims, filler, decorative slogans and manufactured contrasts. Avoid stock phrases such as “leverage my unique blend,” “passionate professional,” and “dynamic landscape.”
6. Prefer concrete verbs. Vary sentence length when a paragraph becomes repetitive. Keep the writing readable aloud.
7. Remove unsupported superlatives. Name the scope: a prototype, internal workflow, customer deployment or production system are different claims.
8. Keep interface text short. Show instructions where a user needs them; do not explain implementation details in the primary visual.

Before delivery, compare every factual sentence with its source. Mark unresolved claims in the private draft and ask for confirmation; never leave those placeholders in submitted material. Read the final text aloud, remove repetition, then verify dates, names, links and numbers again. Save the edited document beside its source references and approval record.
