# Discover direction

Read `../SESSION.md` and `../stop-slop/SKILL.md`.

**Inputs:** available resumes, user goals, existing settings and evidence. No prior conversation is required.

1. Inventory source files and available tools. Ask one focused question about the user's most important missing constraint. Continue with document review while waiting.
2. Establish role duties they want, duties they want to avoid, compensation type and floor, currency, locations, work arrangements, start date, exclusions and work authorization questions that need their input.
3. Probe overlooked experience: what they built, delivered, owned, taught or improved. Separate an interest from demonstrated experience.
4. Propose up to 20 ranked role families. For each, list supporting evidence, a duty-level fit, gaps and original employer titles to search. Do not fill all 20 with weak matches.
5. Record available browser, connectors, document tools and agent support. Use a single-agent sequence when delegation is unavailable.
6. Summarize settings for the user and save their corrections. Save unresolved questions with the next action.

**Outputs:** private session, evidence inventory and editable canonical settings/role families. Use the career API documented in `docs/CAREER-CONTROL.md` if available; inspect its current schema before writes. Save a pending draft when the API cannot represent an answer.

**Approval gates:** Confirm proposed preferences with the user. This session does not authorize applications or approve a resume template.

**Completion checks:** Compensation distinguishes base, total cash and contract rate; locations and exclusions are explicit; ranked roles reference evidence; gaps remain visible; unresolved required questions keep the session open.
