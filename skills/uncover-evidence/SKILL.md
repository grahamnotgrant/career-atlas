# Uncover evidence

Read `../SESSION.md` and `../stop-slop/SKILL.md`.

**Inputs:** one role requirement or uncertain resume claim, relevant artifacts and prior answers.

1. Pick the highest-impact unknown. Ask the user to describe a specific instance.
2. Probe their own actions: initial problem, constraints, decisions, implementation, collaborators, failure modes, verification and result. Ask one follow-up at a time.
3. Inspect authorized artifacts where available. Repository code proves that code exists; it does not alone prove the user's authorship, enterprise rollout or customer adoption.
4. Record the user's exact scope and distinguish personal work from team work. Separate measured outcomes from estimates and aspirations.
5. Draft a defensible resume bullet and a short interview story. Read them back for factual correction.

**Outputs:** private evidence note with source IDs, ownership boundaries, unresolved gaps, approved wording and a resumable session.

**Approval gates:** The user confirms new factual claims before they enter a template or application. A hypothesis remains a hypothesis.

**Completion checks:** Claim has an actor, action and supported result; implementation details withstand follow-up; no invented numbers; user corrections preserved. Respect requests to skip or stop and save the next question.
