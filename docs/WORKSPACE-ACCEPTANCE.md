# Workspace acceptance

Verified on October 27, 2026 with Node.js 26.8.2 on macOS. This records the delivered workspace scope from [issue #2](https://github.com/grahamnotgrant/career-atlas/issues/2); it is not a claim of support for untested operating systems or external agent providers.

## Delivered

- A default task-focused Work screen; the globe/journey remains available. Compact layouts, exact scope disclosures and persistent drafts support embedded panels.
- Durable runs, exact questions/answers, pending instructions, agent acknowledgment/completion, source checkpoints, observed facts, exact wording approvals and immutable application-attempt materials.
- Shared authenticated, revision-checked, idempotent commands through the app and CLI, with capability discovery and paginated audit history.
- Same-ID recovery after uncertain delivery and browser reload; a dirty form prevents automatic build reload. Displayed revisions guard against approving unseen changes.
- Material completeness separated from existing resume evidence and confirmed outcomes. Source scope changes do not inherit unrelated coverage.
- Existing grants, claims and receipt requirements retained. Pause/revoke and preference changes are reviewable in the app. Questions and wording approvals do not expand application authority.
- Additive schema-v5 migration with backup, workspace-aware export revisions and managed material hash validation on backup/restore.
- Updated shared career workflows, career-daily, startup/session/documentation contracts and a fictional cross-profession workspace example.

## Current limits

The external agent reads pending instructions on start/resume; this release does not bundle a model or an automatic cross-chat wakeup service. Detailed source authorization notes and original files remain private. Importing a selected session bridges its progress; it does not silently migrate every historical session or invent past materials/answers.

Managed document previews remain PDF/plain text. Other original formats and portfolio links retain identity and coverage in material inventories; a converted preview cannot establish submitted bytes. External references are not copied by backup automatically.

Current acceptance exercised Codex/local command operation and Chromium on macOS. Linux, Windows and a live Claude-provider walkthrough were not exercised in this run. The existing large-client-bundle build warning remains; the measured scale target passed.
